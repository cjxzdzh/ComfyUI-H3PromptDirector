# 海螺网页端自然语言兼容格式

来源：MiniMax／海螺官方使用手册，核对日期 2026-08-03：
https://vrfi1sk8a0.feishu.cn/wiki/FIWjwgL33ipnkekzk30crmKUnIh

仅在用户明确使用海螺网页、App，或要求中文自然语言提示词时使用。不要把该格式作为本地开源 H3-Base 的默认 Context-IR。

## 三段式

`完整提示词 = 参考素材说明 + 核心创意 + 画面过程说明`

1. 参考素材说明：有上传素材时，按界面顺序使用 `@图片1`、`@视频1`、`@音频1`，明确每项职责与保留要求。
2. 核心创意：一句话说明主体、地点、事件、类型或风格。
3. 画面过程说明：沿时间或故事线写景别、可见内容、动作、运镜、对白和声音。

## 规则

- 图片作为首帧或尾帧时明确位置；人物或风格参考不要误写成首帧。
- 视频用于动作、运镜、分镜、剪辑或源视频时明确只参考哪些属性。
- 音频用于音色、对白、音乐或节奏时说明完整复用、局部复用或仅参考。
- 多镜头写清切换方式和承接元素；一镜到底使用连续动作链，不混用切镜。
- 精确对白、歌词、字幕、标题和画面文字逐字写出并使用引号。
- 不要背景音乐时写：`非叙事性音乐：N/A；不要添加背景音乐。`

网页端输出仍必须在代码块外告诉用户应选择 FL2VA 或 Ref2VA；不要把该元信息放入生成提示词正文。
